# Smooth N Shine User Dashboard

A responsive single-page user dashboard for Smooth N Shine.

## Features
- Fixed desktop sidebar
- Fixed top header
- Responsive mobile sidebar with overlay
- All sidebar items open inside the same main content area
- URL hash navigation (`#appointments`, `#treatments`, etc.)
- Dashboard, appointments, treatments, treatment plan, before/after, prescriptions, reports, payments, notifications, reviews, profile, settings and logout screens
- Bootstrap Icons
- Responsive cards, tables, forms and progress indicators

## Run
Open `index.html` in a browser.

## Backend integration
Replace the demo data in `app.js` with API calls. The current `data-page` routing can remain unchanged when connecting ASP.NET/PHP/Node APIs.
